# Box 应用 UI 风格重设计需求文档 (PRD)

## 1. 背景与目标
为了提升用户在 TV 端的操作体验，Box 应用需要进行全面的视觉形象升级。目前的设计风格较为保守且功用性过强，缺乏高端感和现代互动体验。
本次重设计的目标是打造一个**科技感、高端且丝滑**的视频交互界面。

## 2. 核心视觉规范
### 2.1 色彩方案 (Theming)
- **背景主色**：`#101017` (Deep Midnight Black)
- **容器背景**：`#1A1A26` (Dark Navy)
- **强调色**：`#A68DFE` (Neon Violet) 或 `#00E5FF` (Cyan Spark)
- **文字色**：主要 `#FFFFFF` (90% 不透明度)，次要 `#B0B0C0`

### 2.2 形状与布局
- **圆角半径**：
    - 大容器/按钮：`24dp`
    - 小元素/标签：`12dp`
- **间距**：全局增加内边距，提升界面的纵深感和透气性。

### 2.3 视觉特效
- **毛玻璃效果**：在弹窗和播放控制栏底部增加半透明高斯模糊背景模拟。
- **渐变**：使用 `Layer-list` 或 `GradientDrawable` 实现多层线性渐变。

## 3. 功能模块升级需求
### 3.1 首页导航
- 升级顶部功能图标，采用等线图标设计。
- 选中的分类项应有明显的“光晕”或“呼吸灯”动效。

### 3.2 视频播放器 (VOD & Live)
- 控制条背景改为从底部向上的暗色渐变。
- 按钮焦点时放大 1.1 倍，并带有强调色边框。

## 4. 技术实现要点
- 优先使用 XML Drawable 实现效果，以保证在 TV 端低性能硬件上的流畅度。
- 全量更新 `colors.xml` 和 `styles.xml`。
- 引入 `Material Design` 的阴影和海拔（Elevation）概念。
